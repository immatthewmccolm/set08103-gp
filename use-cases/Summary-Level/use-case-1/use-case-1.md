# USE CASE 1: Produce reports about population data

## CHARACTERISTIC INFORMATION

### Goal in Context

As an organisation member, I want to be able to view reports of population data, so that I can use those reports for my organisation.

### Scope

Company/Organisation

### Level

Summary (a collection of goals. Could not reasonably be complete in one sitting by one person).

### Preconditions

Database integration merged into master. (complete)

### Success End Condition

Reports about countries, cities, capital cities etc. will be available for viewing for the organisation member.

### Failed End Condition

No reports are ever produced. We fail the coursework.

### Primary Actor

Organisation member.

### Trigger

A request for reports is sent to an organisation member.

## MAIN SUCCESS SCENARIO

1. Organisation member requests reports.
2. Reports received. Information is provided.
3. An organisation member takes next steps to deal with information (compare with information about percentage of languages spoken, total population etc.)

## EXTENSIONS

1. Make a script that runs a collection of related reports, instead of one at a time. 
2. Provide appropriate integration with the other two use cases defined (populations and languages)

## SUB-VARIATIONS

None.
