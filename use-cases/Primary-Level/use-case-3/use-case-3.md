# USE CASE 3: Produce reports about the number of people that speak certain languages.

## CHARACTERISTIC INFORMATION

### Goal in Context

As an organisation member, I want to be able to view the number of people that speak certain languages, so that I can use this information alongside the reports. These should be ordered from greatest to smallest, including a percentage of the world population.

### Scope

Company/Organisation

### Level

Primary (could reasonably be done in one sitting, after some reports are available).

### Preconditions

Database integration merged into master. (complete)
Have reports ready, to compare as organisation member requested. (incomplete)

### Success End Condition

Reports about the number of people that speak certain languages will be available for viewing for the organisation member.

### Failed End Condition

The organisation member can only see the reports, but has no baseline to compare as requested. We fail the coursework.

### Primary Actor

Organisation member.

### Trigger

A request for reports is sent to an organisation member.

## MAIN SUCCESS SCENARIO

1. Organisation member requests reports, either after receiving some/or all of the reports from use case 1 or an independent request.
2. Reports received. Information is provided.
3. An organisation member takes next steps to deal with information (compare with information about population reports, other reports about continents and countries etc.)

## EXTENSIONS

None.

## SUB-VARIATIONS

None.
