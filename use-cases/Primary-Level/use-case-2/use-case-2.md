# USE CASE 2: Produce reports about the population about various sects of the world (from the entire world, to the population of a single city)

## CHARACTERISTIC INFORMATION

### Goal in Context

As an organisation member, I want to be able to view information about the world, so that I can use that information along with the reports.

### Scope

Company/Organisation

### Level

Primary (could reasonably be done in one sitting, after some reports are available).

### Preconditions

Database integration merged into master. (complete)
Have reports ready, to compare as organisation member requested. (incomplete)

### Success End Condition

Reports about the population of continents, countries etc. will be available for viewing for the organisation member.

### Failed End Condition

The organisation member can only see the reports, but has no baseline to compare as requested. We fail the coursework.

### Primary Actor

Organisation member.

### Trigger

A request for reports is sent to an organisation member.

## MAIN SUCCESS SCENARIO

1. Organisation member requests reports, either after receiving some/or all of the reports from use case 1 or an independent request.
2. Reports received. Information is provided.
3. An organisation member takes next steps to deal with information (compare with information about percentage of languages spoken, other reports about continents and countries etc.)

## EXTENSIONS

None.
